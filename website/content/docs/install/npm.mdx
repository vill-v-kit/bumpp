作为项目的开发依赖安装（要求 Node.js 20.19+ 或 22.12+），用你习惯的包管理器：

<Tabs defaultValue="npm">
<PMTabsList />
<Tab value="npm">

```sh
npm install -D @vill-v/bumpp
```

</Tab>
<Tab value="yarn">

```sh
yarn add -D @vill-v/bumpp
```

</Tab>
<Tab value="pnpm">

```sh
pnpm add -D @vill-v/bumpp
```

</Tab>
<Tab value="bun">

```sh
bun add -D @vill-v/bumpp
```

</Tab>
<Tab value="aube">

```sh
aube add -D @vill-v/bumpp
```

</Tab>
<Tab value="nub">

```sh
nub add -D @vill-v/bumpp
```

</Tab>
</Tabs>

npm 包内自带当前平台的预编译原生模块，支持情况：

| 平台 | 预编译原生模块 |
| --- | --- |
| macOS（Apple Silicon） | ✔ |
| macOS（Intel） | ✘ |
| Linux（x64 / arm64，glibc 与 musl——Alpine 可直接使用） | ✔ |
| Windows（x64 / arm64） | ✔ |

<Callout type="warn">
**不支持 Intel Mac**（darwin-x64）——Intel Mac 用户请改用 [crates.io 安装](/docs/install/crates-io)（`cargo install vbumpp`，或 `cargo binstall vbumpp` 自动回退源码编译），功能完全一致。
</Callout>

如果你的项目托管在某个代码平台上，并希望发版后**自动在该平台创建 Release**，改装对应的平台包（即内置了默认平台的 `@vill-v/bumpp`，用法完全相同）：

| 平台 | 包名 |
| --- | --- |
| GitHub | `@vill-v/bumpp-github` |
| GitLab | `@vill-v/bumpp-gitlab` |
| Gitee | `@vill-v/bumpp-gitee` |
| GitCode | `@vill-v/bumpp-gitcode` |

## 运行

装成开发依赖后，通过包管理器运行（也可以在 package.json 的 scripts 里加一条 `"release": "vbumpp"`，之后用 `npm run release` 等方式调用）：

<Tabs defaultValue="npm">
<PMTabsList />
<Tab value="npm">

```sh
npx vbumpp
```

</Tab>
<Tab value="yarn">

```sh
yarn vbumpp
```

</Tab>
<Tab value="pnpm">

```sh
pnpm vbumpp
```

</Tab>
<Tab value="bun">

```sh
bunx vbumpp
```

</Tab>
<Tab value="aube">

```sh
aube x vbumpp
```

</Tab>
<Tab value="nub">

```sh
nubx vbumpp
```

</Tab>
</Tabs>

<Callout type="info">
想全局使用也可以 `npm i -g @vill-v/bumpp`，之后在任何目录直接敲 `vbumpp`。
</Callout>

## 用 mise 安装

[mise](https://mise.jdx.dev) 用户也可以把 vbumpp 装进 mise 工具链：

```sh
mise use -g npm:@vill-v/bumpp
```
