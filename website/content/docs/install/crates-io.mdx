不需要 Node.js 环境时，原生 CLI（纯 Rust 编写，功能与 npm 版完全一致）可以直接从 crates.io 安装：

```sh
cargo install bumpp-cli
```

安装后命令为 `vbumpp`：

```sh
vbumpp --help
```

升级重装同一条命令（`cargo install` 会覆盖到最新版）。
