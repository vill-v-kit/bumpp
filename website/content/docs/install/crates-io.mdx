不需要 Node.js 环境时，原生 CLI（纯 Rust 编写，功能与 npm 版完全一致）可以直接从 crates.io 安装。

## 免编译安装（推荐）

通过 [cargo-binstall](https://github.com/cargo-bins/cargo-binstall) 直接下载 GitHub Release 上的预编译二进制，跳过本地源码编译：

```sh
cargo binstall vbumpp
```

预编译产物与各安装方式的覆盖矩阵：

| 平台 | npm 包 | 原生 CLI 预编译（binstall） | 源码编译（cargo install） |
| --- | --- | --- | --- |
| macOS（Apple Silicon） | ✔ | ✔ | ✔ |
| macOS（Intel） | ✘ | ✘ | ✔ |
| Linux x64（glibc） | ✔ | ✔ | ✔ |
| Linux arm64（glibc） | ✔ | ✔ | ✔ |
| Linux x64（musl，Alpine 等环境可直接运行） | ✔ | ✔ | ✔ |
| Linux arm64（musl，Alpine 等环境可直接运行） | ✔ | ✔ | ✔ |
| Windows x64 | ✔ | ✔ | ✔ |
| Windows arm64 | ✔ | ✔ | ✔ |
| 其他平台 | ✘ | 自动回退源码编译 | ✔ |

不在覆盖列表里的平台（如 Intel Mac）走 binstall 会自动回退为源码编译，与下方的 `cargo install` 等价。

## 源码编译安装

```sh
cargo install vbumpp
```

安装后命令同为 `vbumpp`：

```sh
vbumpp --help
```

升级重装同一条命令（binstall 亦然）。

## 用 mise 安装

[mise](https://mise.jdx.dev) 用户可以把 vbumpp 当作 cargo 工具直接装进工具链：

```sh
mise use -g cargo:vbumpp
```
